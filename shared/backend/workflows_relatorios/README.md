# Workflows e Relatórios

Domínio compartilhado responsável por pendências, aprovações, auditoria, observabilidade, roadmap, exportações e relatórios oficiais.

## Escopo
- Pendências
- Aprovações
- Atenção sua
- Auditoria
- Observabilidade
- SLA
- Roadmap
- Exportações oficiais
- Relatórios gerenciais
- Relatórios regulatórios

## Regra
Workflows e relatórios devem preservar rastreabilidade, tenant_id, auditoria e evidência de origem.
