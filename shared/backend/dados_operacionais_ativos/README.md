# Dados Operacionais e Ativos

Domínio compartilhado responsável por ativos, sensores, tags, SCADA, IoT, calibração e qualidade dos dados operacionais.

## Escopo
- Ativos físicos
- Sensores
- Instrumentos
- Tags
- SCADA
- IoT
- Calibração
- Validação de dados
- Qualidade dos dados
- Resolução de conflitos entre fontes

## Regra
Este domínio define as regras canônicas para confiabilidade, completude e validade dos dados operacionais.
