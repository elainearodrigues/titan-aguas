# Identidade, Segurança e Privacidade

Domínio compartilhado responsável por identidade, acesso, segurança da informação e privacidade.

## Escopo
- RBAC
- Perfis de usuário
- 2FA
- Sessões
- LGPD
- Vault e credenciais
- Segurança da informação
- Retenção
- Continuidade

## Regra
Nenhuma interface deve implementar regras próprias de acesso, privacidade ou segurança fora deste domínio compartilhado.
