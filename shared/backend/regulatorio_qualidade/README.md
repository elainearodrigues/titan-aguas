# Regulatório e Qualidade

Domínio compartilhado responsável por normas, qualidade, laboratório, amostragem, outorgas e conformidade regulatória.

## Escopo
- Laboratório
- Amostragem
- Cadeia de custódia
- Outorgas
- Parâmetros legais
- Pacotes regulatórios
- Portaria GM/MS 888/2021
- CONAMA
- ANA
- ARSESP
- Conformidade normativa

## Regra
As regras regulatórias devem ser versionadas, rastreáveis e aplicadas de forma consistente em todo o TITAN Águas.
