# Governança da Plataforma

Domínio compartilhado responsável por funcionalidades transversais da plataforma TITAN Águas.

## Escopo
- Recursos e funcionalidades
- Feature flags (recursos de ativação)
- Configurações globais
- Tarefas agendados
- Operações em lote
- Fases evolutivas
- Controle de capacidades habilitadas

## Regra
Este domínio contém funções canônicas reutilizáveis por admin, prestador, governança_admin e governança_prestador.
