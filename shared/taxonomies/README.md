# Taxonomias Compartilhadas

Este diretório contém as taxonomias canônicas do TITAN Águas.

## Finalidade

Padronizar códigos, estados, classificações e vocabulários usados por todas as interfaces:

- admin
- prestador
- governanca_admin
- governanca_prestador

## Regra

Taxonomias não executam lógica.  
Elas definem os valores oficiais permitidos.

## Exemplos

- estados da planta
- níveis de severidade
- níveis de qualidade de dados
- tipos de evento
- categorias regulatórias
