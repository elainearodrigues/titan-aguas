# Estrutura, Planta e Estado

Domínio compartilhado responsável pela estrutura das entidades de saneamento e pelo cálculo canônico do estado da planta.

## Escopo
- Prestador
- Município
- Sistema produtor
- Planta
- Manancial
- Corpo receptor
- Estrutura de prestação
- Estado de implantação
- Estado operacional

## Funções canônicas
- calcular_estado_planta

## Regra
O estado da planta deve ser calculado exclusivamente por função canônica deste domínio.
